TASK 1 - MOVIE MANAGEMENT SYSTEM

Technology:
- Python
- Django 4.2
- SQLite
- HTML
- CSS

Features:
- Movie management
- Genre and language management
- Cast management
- Theater and show management
- YouTube trailer
- Multiple movie posters
- Age certification
- Movie duration and description
- User registration and login
- Movie booking
- Ratings and reviews
- Verified viewer badge
- Review editing
- Review reporting
- Similar movies
- Trending movies
- Recently released movies

How to Run:

1. Create/activate the virtual environment.
2. Install Django.
3. Open the project folder.
4. Run:
   python manage.py migrate
5. Run:
   python manage.py runserver
6. Open:
   http://127.0.0.1:8000/
